# Student Management System

## Problem Statement

Managing student records manually can be time-consuming and may lead to errors or difficulty in finding and updating information.

The **Student Management System** is a Python-based console application developed to manage student records efficiently. The system stores important student information such as Student ID, Name, Age, Course, and Marks.

The application allows users to add, view, search, update, and delete student records. It also calculates the grade of each student based on their marks and calculates the average marks of all registered students.

The main objective of this project is to provide a simple and organized system for managing student information while demonstrating the use of Python and Object-Oriented Programming concepts.

---

## Scope of the Project

The scope of this project includes:

- Adding new student records.
- Viewing all registered students.
- Searching for a student using Student ID.
- Updating existing student information.
- Deleting student records.
- Preventing duplicate Student IDs.
- Calculating student grades based on marks.
- Calculating the average marks of all students.
- Providing a simple menu-driven console interface.
- Demonstrating Object-Oriented Programming concepts in Python.

### Out of Scope

The current version of the project does not include:

- Database connectivity.
- User authentication or login.
- Web or mobile interface.
- Attendance management.
- Fee management.
- Examination scheduling.
- Permanent file-based data storage.

## High-Level Features

### 1. Add Student

Allows the user to add a new student by entering:

- Student ID
- Name
- Age
- Course
- Marks

The system checks whether the Student ID already exists before adding the student.

### 2. View All Students

Displays the details of all registered students, including their calculated grade.

### 3. Search Student

Allows the user to search for a student using their Student ID.

### 4. Update Student

Allows the user to update:

- Name
- Age
- Course
- Marks

If the user leaves a field blank, the existing value is retained.

### 5. Delete Student

Allows the user to delete a student record using the Student ID.

### 6. Grade Calculation

The system automatically calculates the student's grade based on their marks.

| Marks | Grade |
|-------|-------|
| 90 and above | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

### 7. Calculate Average Marks

The system calculates the average marks of all registered students and displays the result up to two decimal places.

### 8. Menu-Driven Interface

The system provides a simple menu with the following options:

1. Add Student
2. View All Students
3. Search Student
4. Update Student
5. Delete Student
6. Calculate Average Marks
7. Exit
